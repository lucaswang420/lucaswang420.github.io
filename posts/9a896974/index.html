Gemma 4 31B Q5_K_M + llama.cpp Windows 本地部署教程

纯 Windows 下最简可用方案，使用预编译版 llama.cpp，无需自行编译，按步骤操作即可运行。

1. 硬件要求

项目 要求
显存 ≥ 20GB 全 GPU 加载（RTX 4090 / 4090D / 3090 / A100 等）
显存不足时 < 20GB 会自动切部分到内存，速度变慢
内存 建议 32GB 以上
硬盘 模型文件约 22GB

2. 下载 llama.cpp Windows 预编译包

不用自己编译，直接下载发布版：

  1. 打开 llama.cpp Releases
  2. 找到最新版中的 **llama-bin-win-cuda-x64.zip**（NVIDIA 显卡必须下 CUDA 版）

4.1 聊天交互模式（最常用）

关键参数说明：

参数 含义
-m 模型文件路径
-ins 指令微调模式（Gemma IT 版必须加）
-c 8192 上下文窗口 8K tokens
-ngl 999 全部层加载到 GPU（速度最快）
--temp 0.7 回答创意程度（0-1，越高越随机）
--repeat_penalty 1.1 重复惩罚系数

4.2 启动 API 服务（兼容 OpenAI 格式）

启动后访问 http://127.0.0.1:8080 可使用：

  • /v1/chat/completions — 兼容 OpenAI Chat API
  • /v1/models — 模型列表
  • 内置网页聊天界面

5. 显存不够的解决方案

如果显卡只有 16GB 显存，31B Q5_K_M 会爆显存，有以下方案：

方案 1：降低 GPU 加载层数

数字越小，越依赖内存，速度越慢。

方案 2：换更小的量化版本

量化版本 约占空间 显存需求
Q5_K_M ~22GB ≥ 20GB
Q4_K_M ~18GB ≥ 16GB
Q3_K_M ~14GB ≥ 12GB

6. 常见问题

Q1: 报错 “cuMemAlloc failed”

显存不够。减少 -ngl 数值，或换用 Q4_K_M 量化版本。

Q2: 找不到 cudart64_xx.dll

需要安装 NVIDIA CUDA Toolkit 12.x。

Q3: 推理速度很慢

排查步骤：

  1. 确认使用的是 CUDA 版本（llama-bin-win-cuda-x64.zip）
  2. 确认 -ngl 999（全部层在 GPU 上）
  3. 关闭其他占用显存的程序（浏览器、游戏等）
