本地部署 Qwen2.5-Coder-14B

基于 llama.cpp 在 Windows 上本地部署 Qwen2.5-Coder-14B，面向 RTX 5060 (8GB VRAM) + Core Ultra 7 (48GB DDR5) 硬件环境。

1. 安装 CUDA Toolkit

官方下载

CUDA Toolkit 下载页

显卡驱动版本较新（591.59），建议直接安装最新版（当前为 CUDA Toolkit 13.x）。

下载步骤

  1. Operating System: Windows
  2. Architecture: x86_64
  3. Version: 11（对应 Windows 11）
  4. Installer Type: exe (local) — 推荐 Local 版（约 3GB+），包含完整文件，安装更稳定
  5. 点击 Download 开始下载

历史版本

如需特定旧版本，访问 CUDA Toolkit Archive。

安装重要提示 (必看)

  1. 安装选项：运行安装程序时，推荐选择 **”Custom (Advanced)”**（自定义）。
  2. 关键组件：务必勾选 **”Visual Studio Integration”**，这是编译 llama.cpp 所必须的。
  3. 重启生效：安装完成后，必须关闭并重新打开您的 CMD 或 PowerShell 窗口，nvcc --version 命令才会生效。

验证安装

能输出版本号即表示环境变量生效。

⚠️ 务必使用 **”x64 Native Tools Command Prompt for VS 2022”**（开始菜单搜索 “Native”），不要用普通 CMD。

5. 参数说明

参数 值 说明
-ngl 32 GPU 卸载层数。Qwen 2.5 14B 共 48 层，设为 32 卸载约 66% 到 8GB VRAM（占用约 6.5–7GB），剩余 16 层由 CPU 处理，兼顾速度与稳定性
-t 12 CPU 线程数。Ultra 7 虽有 20 核，但多为低功耗 E-Core，12 线程锁定高性能 P-Core 并匹配双通道内存带宽
-c 8192 上下文窗口大小。8K token 是 8GB 显存的安全上限，足以处理较长的代码文件
-fa on Flash Attention，降低注意力计算的显存占用并加速长 prompt 处理
-co on 对话模式，自动识别 Qwen 的聊天模板，实现类 ChatGPT 交互

6. 性能调优

  • 蓝屏 / 崩溃 / 程序闪退 → 显存溢出，将 -ngl 32 降至 28 或 25
  • 显存余量充足 → 任务管理器 → 性能 → GPU 查看占用，可尝试提高至 -ngl 35 以加速生成
