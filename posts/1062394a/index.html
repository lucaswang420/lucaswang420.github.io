Cloudflare WARP 远程控制：通过 Tunnel 实现 RDP 远程桌面

在台式机上安装 Cloudflare Tunnel，笔记本通过 Cloudflare One Client 用 RDP 远程连接台式机。 整个过程不需要公网 IP、不需要开放端口。

整体架构

第一步：在台式机上开启远程桌面

  1. 台式机（Windows）→ 设置 → 系统 → 远程桌面 → 开启
  2. 记下台式机的内网 IP 地址（如 192.168.1.100）
    • 打开 CMD，运行 ipconfig，找到 IPv4 地址
  3. 确认你知道台式机的 Windows 用户名和密码

第二步：在台式机上安装 Cloudflare Tunnel

  1. 前往 Connectors 页面
  2. 点击 创建 Tunnel → 选择 Cloudflare Tunnel
  3. 给 Tunnel 命名（如 home-desktop）
  4. 按页面提示，在台式机上安装 cloudflared：
    • Windows：下载 cloudflared.exe，以服务方式安装
    • 页面会提供安装命令和 Token，直接复制到台式机运行
  5. 安装完成后，Tunnel 状态应显示为 Healthy（健康）

第三步：配置私有网络路由

  1. 前往 Routes 页面
  2. 点击 Create route → 选择 Tunnel CIDR
  3. 选择你刚创建的 Tunnel（home-desktop）
  4. 输入台式机的 IP 地址（如 192.168.1.100/32）
    • 如果想访问家里整个网络，可以输入 192.168.1.0/24
  5. 点击 Create route

第四步：配置 Split Tunnel（确保流量走 Tunnel）

  1. 前往 Zero Trust → Settings → Device settings → 编辑你的设备配置文件
  2. 找到 Split Tunnels 部分
  3. 确保台式机的 IP 范围（如 192.168.1.0/24）在 Include（包含）列表中，不在 Exclude（排除）列表中
    • 如果默认配置已包含所有局域网 IP，则无需额外操作

第五步：从笔记本远程连接

  1. 确保笔记本上的 Cloudflare One Client 已连接（状态显示绿色/已连接）
  2. 打开 Microsoft Remote Desktop（远程桌面）
    • Windows 自带，或从 Microsoft Store 下载
  3. 点击 添加 PC
  4. PC name：输入台式机的内网 IP（如 192.168.1.100）
  5. 用户账户：输入台式机的 Windows 用户名和密码
  6. 双击连接 → 选择 继续

连接成功后，你就可以在公司笔记本上远程操控家里的台式机了。

注意事项

  • 台式机必须保持开机且不能休眠（可在电源设置中关闭休眠）
  • cloudflared 服务必须保持运行（安装为 Windows 服务后会自动启动）
  • 如果连接不上，检查台式机防火墙是否允许 RDP（3389 端口）
