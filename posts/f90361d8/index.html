Antigravity CLI 接入指南

Google Antigravity 提供的命令行工具 agy，可在终端中调用 Antigravity 的 AI 能力。本文记录在 Windows 下通过本地代理接入的步骤。

概览

  • 工具名称：agy（Antigravity CLI）
  • 官方下载：https://antigravity.google/product/antigravity-cli
  • 登录方式：Google 账号
  • 适用平台：Windows（本文示例）；macOS / Linux 思路相同，仅环境变量写法不同

前置条件

  1. 已安装 Node.js（agy 依赖 Node 运行环境）。
  2. 本地代理软件已启动，并已知其代理端口（下文示例为 7897）。
  3. 拥有可登录的 Google 账号。

💡 先确认代理端口：在代理软件（如 Clash / v2ray 等）的设置里查看 HTTP 代理端口，下文脚本中的 7897 需替换成你的实际端口。

环境变量说明

变量 作用 说明
NODE_TLS_REJECT_UNAUTHORIZED 0 表示跳过 TLS 证书校验 走代理时避免证书问题，仅本地使用，存在 MITM 风险
HTTP_PROXY HTTP 请求代理地址 端口需与代理软件一致（示例 7897）
HTTPS_PROXY HTTPS 请求代理地址 同上

⚠️ 安全提示：NODE_TLS_REJECT_UNAUTHORIZED=0 会关闭 TLS 校验。当前脚本仅对 agy 进程生效，风险可控。如需更安全，可改为把代理的根 CA 证书加入 Node 信任库，而非全局关闭校验。

常见问题

  • agy 命令找不到：确认已完成安装且对应目录在系统 PATH 中。echo %PATH% 检查。
  • 登录/请求超时：确认代理软件已开启、端口与脚本中一致；curl -x http://127.0.0.1:7897 https://www.google.com 测试代理是否通。
  • 证书报错：保留 NODE_TLS_REJECT_UNAUTHORIZED=0，或改用导入根 CA 证书的方式。
