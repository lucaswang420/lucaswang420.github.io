🎯 推荐图片资源

首页背景图

  • 尺寸: 1920x1080 或更高
  • 格式: JPG/PNG
  • 风格: 科技感、抽象、代码相关
  • 推荐:
    • 代码雨效果
    • 抽象几何图形
    • 宇宙星空
    • 科技线条

文章封面图

  • 尺寸: 1200x630 (社交媒体标准)
  • 格式: JPG/PNG
  • 内容: 与文章相关的视觉元素

全局背景图

  • 尺寸: 1920x1080 或可平铺
  • 透明度: 建议使用半透明背景
  • 格式: PNG（支持透明）

📹 视频背景要求

视频格式

  • 推荐格式: MP4 (H.264编码)
  • 备选格式: WebM
  • 分辨率: 1920x1080
  • 时长: 建议10-30秒循环

视频内容

  • 抽象动画
  • 粒子效果
  • 代码滚动
  • 几何图形
  • 技术演示

文件大小

  • 建议 < 5MB
  • 使用压缩优化
  • 考虑加载速度

🚀 性能优化建议

  1. 图片优化

    • 使用 WebP 格式
    • 压缩图片文件
    • 使用 CDN 加速

  2. 视频优化

    • 设置合适的比特率
    • 预加载首帧
    • 移动端禁用

  3. 效果控制

    • 移动端禁用复杂效果
    • 使用 prefers-reduced-motion 媒体查询
    • 性能较差的设备自动降级

🎨 设计建议

配色方案

  • 主色调：蓝色系 (#49B1F5)
  • 辅助色：紫色系、青色系
  • 对比度：确保文字可读性

视觉层次

  • 背景透明度：0.1-0.2
  • 粒子效果：适度不过度
  • 动画速度：适中不晕眼

响应式

  • 移动端简化效果
  • 确保各种设备兼容
  • 触摸友好交互

📞 使用帮助

如果需要：

  1. 制作背景图片 - 可以使用 Canva、Figma 等工具
  2. 视频编辑 - 使用 Premiere Pro、Final Cut Pro
  3. 效果调试 - 修改配置文件并预览
  4. 性能优化 - 检查页面加载速度

更多技术支持请查看 Butterfly 主题文档
